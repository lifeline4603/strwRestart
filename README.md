# strwRestart
a very simple restart sequence for gmod based on a meme

## roots of this epic addon
so have you ever seen [this video (click)](https://www.youtube.com/watch?v=zfQR0Ge2-ag)? well, i remade it in gmod for you to use.

## how install
download, drag and drop the strwRestart into addons folder, done

## it no workey
if your server runs on linux (ex: physgun) make sure to lowercase the addon folder (strwRestart to strwrestart)

## it still no workey
you're wrong

## how it workey
admins and superadmins can do !restart and it will immediately blow up the server with the epic meme
it will while true do end the server so make sure to make it automatically restart on crash.
